# hdl-1551-III

Xilinx ISE project and bitstream for the **XC9572XL** on the 1551-III-Pico board (`Fake6523.jed`).

What the CPLD does (TPI ports, RAM/ROM decode, `byte_latched`), how to rebuild with ISE, and how to JTAG-flash: see the [top-level README → CPLD](../README.md#cpld).

Sources are based on [ZXByteman/Fake6523](https://github.com/ZXByteman/Fake6523). The older daughterboard CPLD tree is under [`../experimental/hdl/`](../experimental/hdl/).
